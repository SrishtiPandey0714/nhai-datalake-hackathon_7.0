# NHAI DataLake Hackathon 7.0 – Offline Facial Authentication System

## Team Achievers

An offline-first biometric attendance and authentication system designed for low-connectivity environments using on-device facial recognition, active liveness detection, SQLite persistence, and AWS synchronization readiness.

## Key Features

* 100% Offline Authentication
* Active Liveness Detection
* 512-Dimensional Facial Embeddings
* TensorFlow Lite Edge Inference
* SQLite Local Storage
* Attendance Audit Logging
* AWS Sync & Purge Architecture
* Real-Time Telemetry Dashboard

## Technical Highlights

| Feature            | Value           |
| ------------------ | --------------- |
| Model Size         | 17.79 MB        |
| Embedding Size     | 512 Dimensions  |
| Storage Format     | SQLite BLOB     |
| Template Size      | 2048 Bytes      |
| Processing Latency | <600 ms         |
| Execution          | Fully On-Device |

## Architecture

Camera → MLKit Face Detection → Active Liveness Validation → TensorFlow Lite Inference → Cosine Similarity Matching → SQLite Logging → AWS Sync Queue
